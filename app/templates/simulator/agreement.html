Why trust these numbers?

Microsoft's What If API can only score policies that already exist in a tenant, so it cannot evaluate a draft. This tool implements its own evaluation engine — and then checks that engine against Microsoft's, on this tenant's real policies and real sign-ins. The agreement rate below is that check.

Run the check

Every distinct condition set in the window is evaluated twice — once by this engine, once by Microsoft — and the verdicts are compared, policy by policy. Busiest condition sets go first, so a capped run still covers most real traffic. This makes one API call per condition set, so it is slower than a simulation.
