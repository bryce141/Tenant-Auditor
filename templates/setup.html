Connect your Microsoft 365 tenant

You'll need Global Administrator access and about 5 minutes.

  1. 1
    Go to portal.azure.com and sign in with your admin account. In the top search bar, type App registrations and open it.
  2. 2
    Click + New registration. Give it any name (e.g. Tenant Auditor), leave everything else as default, and click Register.
  3. 3
    On the app's Overview page, copy the Application (client) ID and Directory (tenant) ID — you'll paste these in the next step.
  4. 4
    Open API permissions in the left sidebar. Click Add a permission → Microsoft Graph → Application permissions. Search for and add each of these:
    User.Read.All Policy.Read.All UserAuthenticationMethod.Read.All AuditLog.Read.All Directory.Read.All IdentityRiskyUser.Read.All RoleManagement.Read.All Application.Read.All MailboxSettings.Read
  5. 5
    Still on API permissions, click Grant admin consent for [Your Org] and confirm. Each permission should show a green checkmark.
  6. 6
    Go to Certificates & secrets in the left sidebar. Click New client secret, give it any name, and click Add. Immediately copy the Value — it's only shown once.
    Don't copy the Secret ID — you need the Value column.
App Overview page → Directory (tenant) ID
App Overview page → Application (client) ID
Certificates & secrets → the Value column (not Secret ID)
